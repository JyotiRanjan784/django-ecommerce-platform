# Django E-Commerce Platform

A full-stack e-commerce website built using Python and Django.

## Features

- Product listing
- Product details
- Product search
- Shopping cart
- Checkout
- Order placement
- Order tracking
- Razorpay payment integration
- Blog section
- Contact page
- Admin panel
- Product image management

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Razorpay
- Git & GitHub
